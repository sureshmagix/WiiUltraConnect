# Local validation — Direct edition

Version: **0.2.0-serverless.1**. Branch: **codex/serverless-direct**.

The following checks were run locally on Windows with Electron 44.2.0 and Node.js 22.14.0. This verifies the implemented local behavior; it is not an internet or cross-platform certification.

| Check | Result |
| --- | --- |
| JavaScript syntax | Passed |
| Automated tests | 18 passed |
| Complete offline offer/response round-trip | Passed |
| Expiry, malformed codes, mismatched response, relay rejection | Passed |
| Concurrent/repeated response guard | Passed |
| Cancel/timeout during candidate gathering | Passed |
| Real desktop capture at 1920×1080, 30 FPS target | Passed |
| Real desktop capture at 1920×1080, 60 FPS target | Passed |
| Real WebRTC video decoding and three data channels | Passed |
| ICE servers | Empty on the tested peer connection |
| ICE candidate types | Direct host/peer candidates; no relay or server-reflexive candidates |
| HTTP/HTTPS/WebSocket service requests | None observed; blocked during the integration test |
| Signaling server/listener | None started by app or test runner |
| Legacy server environment variables | Ignored, including an invalid old ICE configuration |
| Chat both directions and HTML-safe rendering | Passed |
| Files both directions, receiver acceptance and acknowledgement | Passed |
| Transferred file contents | SHA-256 comparison passed |
| Input before local host consent | Rejected |
| Native input bindings | Loaded; physical input was not injected |
| Session teardown | Tracks/channels stopped; input disabled |

Integration reports and screenshots are generated by `npm run smoke` and `npm run smoke -- 60` under `artifacts/serverless/` and are intentionally not committed because they contain machine-specific data. The test's video decoder initially adapts to a lower resolution; the capture target is not a promise of delivered resolution or frame rate.

Not verified here: two independent internet connections, public IPv6 reachability, NAT/CGNAT traversal, macOS/Linux, mixed-DPI native input, live keyboard/mouse injection, signing/notarization, or installers. No external service is added to compensate for those conditions. Internet use requires a direct reachable path.

The existing optional native-input dependency still produces seven moderate npm audit entries through Jimp/file-type. Received data is not parsed by that image library. See the README for details and the provider-free installation option.
